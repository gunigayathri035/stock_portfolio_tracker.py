# Stock Portfolio Tracker

## Description

This is a Python-based Stock Portfolio Tracker developed as part of my CodeAlpha Python Programming Internship.

The program allows users to:
- Select stocks from a predefined list
- Enter the quantity of stocks
- Calculate the value of each stock
- Calculate the total portfolio value
- Save the portfolio result in a text file

## Technologies Used

- Python
- Dictionary
- Lists
- Loops
- Functions
- File Handling
- Exception Handling

## Sample Stocks

| Stock | Sample Price |
|-------|-------------:|
| AAPL  | $180 |
| TSLA  | $250 |
| MSFT  | $420 |
| GOOGL | $175 |
| AMZN  | $190 |

## Example

If the user enters:

AAPL → 5 shares

TSLA → 2 shares

The program calculates:

AAPL = 5 × $180 = $900

TSLA = 2 × $250 = $500

Total = $1400

## Output

The result is saved in:

`portfolio_result.txt`
